01 Section

Two corrections applied after the first build

CSSI runs on a semester window

CSSI previously carried target_semester = 1, which is only a floor — every student from Semester I upward could see it. It is now a window with three phases, because floating a programme and opening it are different moments.

StudentPhaseWhat they can do
Semester IHidden CSSI does not appear at all
Semester IIAnnounced Sees it and can line up an NGO over the break. Enrolment and every submission are refused with an explanation.
Semester IIIActive Certificate and all other submissions open. Once the certificate is verified, the coordinator allocates a presentation slot.
Semester IV+Concluded No longer open to them

The presentation slot is refused (409) until the certificate is verified — allocating a date to a student who has not completed the internship would put a commitment in front of them that nobody intends to honour.

Coordinator and Mentor are separately assignable

A scoped assignment is now faculty → role → module → department. Coordinator and Mentor are independent grants: neither implies the other, one person may hold several, and permissions resolve as the union so revoking one never removes what another gave.

Minor coordinator scope stays a policy decision

An earlier draft of this work read "Minor coordinator for ICT" as the minors ICT offers, and added an ICT Data Science minor to make that reading work. Both were wrong: the reading was an assumption, and the minor was an invented offering. The minor has been removed, the demo catalogue is now labelled as demo data in the seed, and the interpretation is configuration:

MINOR_COORDINATOR_SCOPEMeans
OFFERING The minors the coordinator's department offers — its seats, ranking policy and allocation rounds
APPLICANT Applications from students of the coordinator's department, whichever department offers the minor
EITHER Default A match on either side is enough. Shipped as the default because locking a real coordinator out of plausibly-theirs work is the worse failure while the policy is unknown.

All three are covered by tests, so switching the rule once the university confirms it is a one-line change with known behaviour. No minor is added to the catalogue unless the university confirms it.

Two more fixes, found by using the app

Seven dead links produced a 404. Dashboard action items, stat cards, calendar deadlines, elective notifications and a seeded announcement all pointed at /academics/electives — a path that has not existed since Open and Core were split into separate screens. Each now resolves the correct screen from the component's own type, and the old path redirects so notifications already stored against it still work.

An expired session stranded the user. The fetch wrapper only ended a session on 401 if a refresh token existed. With none — an expired or revoked session — the 401 fell straight through, so the app rendered its full shell with “Authentication credentials were not provided” in the middle and no way out. Any unrecoverable 401 now clears the session and redirects to sign-in, which then returns the user to the page they were trying to reach.

Security fix — cross-module scope leak. assert_coordinates short-circuited on the coarse permission, and Role.INTERNSHIP_COORDINATOR carries institution-wide internships:manage. The ICT Summer Internship coordinator could therefore manage ICT’s CSSI — precisely what scoped assignments exist to prevent. Only genuinely institution-wide roles now bypass; everyone else needs a matching assignment.

FacultyGrants heldResult
Dr. Priya Nair Coordinator Summer Internship · ICT Manages Summer · ICT. Refused CSSI · ICT, and Summer · CSE.
Dr. Meera Krishnan Coordinator NPTEL/MOOC · ICT
Mentor Summer Internship · ICT		 Both resolve at once. Neither leaks into the other’s module.

Mentor CSSI · ICT		 Sees his mentee screens. No administrative control over either module.

Admin → Role Assignments now carries a Faculty · Role · Module · Department · Status · Actions table with Create, Edit and Revoke, an optional validity window, and a role catalogue that separates which roles exist from who holds them, where. Role and module are immutable on edit — rewriting them in place would misrepresent the audit trail, so revoke and re-create instead. Every change is audit-logged.

05 Section

UI changes

Document panel — shared by student and faculty

One component renders every expected document for the programme, grouped into Weekly Reports, Required Documents, Final Report and Other. A missing mandatory item stays visible as a dashed Not submitted card — it is never silently absent, and it never carries a placeholder link.

RoleWhat they see and can do
Student Status, the reviewer’s rejection reason and timestamp, and an Upload / Replace file button. Weekly reports route to the Reports tab with the week number pre-filled, because a report carries a written summary as well as a file.
Faculty & coordinator The same panel with Start review, Verify and Reject. Rejection opens a modal that requires a reason. View PDF fetches through the authenticated API and opens a blob — the storage path is never exposed.

Progress shows n of m stages complete with the specific blockers listed (“week 3, 5, 6, 7… outstanding”, “Certificate: document is rejected”), replacing the stored percentage. The Proof of Work / Documents tab badge counts outstanding required items, so missing work is visible before the tab is opened.

Minor allocation round

A new coordinator tab shows the declared ranking criteria as an explicit chain, the seat arithmetic, and the full ranked list with the cut-off marked. Preview is a dry run; running the round is confirmed in a modal and notifies every applicant.

Elective administration

Viability and sections tab: per-division breakdown, whether a course runs, and the planned section split.

08 Section

Known limitations

  1. Industry mentor marks have no external portal The rubric component is marked is_external and the student is blocked from entering it (403), but the marks are currently recorded by faculty on the mentor’s behalf. A token-based external form is not built.
  2. View PDF loads the whole file into memory It fetches the file as a blob before opening it. Fine for reports and certificates; a large video would want a streamed, short-lived signed URL.
  3. No virus scanning or content sniffing on upload Extension and size are checked; the bytes are not.
  4. The minor waitlist does not auto-promote If an allocated student withdraws the seat is freed, but the next waitlisted applicant is not promoted automatically — a coordinator re-runs the round.
  5. Notifications are in-app only Twenty-seven real events emit them; there is no email or push transport.
  6. Docker Compose bakes the code into the images Bind mounts fail with EDEADLK under iCloud-synced folders such as ~/Desktop. Live reload is the opt-in docker-compose.dev.yml overlay.
  7. Progress counts stages equally A stage is complete or it is not; there is no weighting, because no weighting has been specified.
  8. The minor coordinator interpretation is unconfirmed "Minor coordinator for ICT" could mean the minors ICT offers or applications from ICT students. Both readings are implemented and selected by MINOR_COORDINATOR_SCOPE; it ships as EITHER until the university confirms which applies. Nothing in the code assumes an answer.
  9. Role and module cannot be edited in place Changing "Mentor for CSSI" into "Coordinator for NPTEL" would rewrite what the audit trail says happened, so the edit form refuses it. Revoke and create instead.
  10. Semester windows assume a single current semester per student A student repeating a semester, or on an off-cycle registration, is treated by their recorded current_semester alone.
  11. Seed data is demo-only Fake names, campushub.example.com addresses, generated PDFs.
